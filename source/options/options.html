Trilium URL

The Trilium URL is the location where Trilium Notes sends data for the creation of a new note. By default, when Trilium Notes is installed on your local machine, it will receive the note on the localhost:port combination below. Otherwise you need to specifiy where Thunderbird needs to send data. Ie: Docker will depends on the port exposed in docker-compose.yml.

TriliumClipper only asks for access to the Trilium server entered above, and only when you allow it. Use the button below to grant that access after saving the URL. If access has not been granted, you will be asked for it the first time you clip a message.

ETAPI Token (Required)

Trilium Notes uses an authentication token to confirm that Thunderbird has permission to create notes. To generate an ETAPI token, you need to open Trilium Notes and click on the Trilium Notes icon in the upper left corner. Then click 'Options' -> 'ETAPI' -> 'Create New ETAPI Token'. After the token is created, store it below.

ParentNoteId

Thunderbird needs to know where in Trilium Notes the software should send the new note. The noteId for any note can be found by clicking the "Note Info" icon (the 'i' within a circle) towards the top of the note. After clicking the icon, you will see the field called "Note ID". Enter that value below.

Message Attachments

This optional feature saves the files attached to an email into Trilium Notes alongside the clipped message. The files are sent straight to Trilium, so there is nothing to set up in Thunderbird and no folder to choose.

Attachment Storage

Trilium Notes can hold a file in two ways, and this option chooses which of them is used for the files attached to a clipped email.

  • Attachments of the note - The files are stored as attachments of the clipped email's note. They do not appear in the note tree, and are reached through the note's "Attachments" tab.
  • Child notes of the note - Each file becomes a note of its own beneath the clipped email's note. The files appear in the note tree, so they can be moved, cloned, and linked to like any other note.

Images are stored so that Trilium displays them, and all other files are stored so that Trilium offers them for download.


The names of the saved files can be listed in the note itself by using the _MSGATTACHMENTLIST placeholder in the Note Content Template described below.

Default Clip Format

Messages can be clipped as plain text, as HTML, as both of them in one note, or as a PDF file. Choose below which of those formats the Trilium button above a message clips in.

Choosing Ask every time instead makes the Trilium button open a menu, so that you pick the format each time you clip a message. With any other setting, pressing the button clips the message straight away in the format chosen here, without showing the menu.

Clipping a message from the message list right-click menu never shows the menu. Those clips use the format chosen below, and use HTML when Ask every time is chosen.

Note that the PDF format renders the message with Thunderbird's own print engine, which requires the message to be open and Thunderbird 121 or later. Choosing PDF as the default format means messages clipped from the message list right-click menu, without being opened first, cannot be clipped.

One of the features of HTML email is the ability to embed graphical images within the message. Clipping those images as part of an HTML clip needs the optional Message Attachments feature described above to be enabled. Other HTML content (character formatting, images hosted on the internet, HTML lists, etc) is still supported even if this is not the case.


Note Filename and Content Templates

Indicate how a clipped email note's filename should appear and how the actual note content should be formatted. Create a template using the following placeholders for message and time information:

  • Note Information:
    • _NOTEDATE - The current date. Fields from the note date are inserted with these other symbols:
      • _NOTEYEAR for a 4 digit year, _NOTEMONTH for a 01-12 month, or _NOTEDAY for a 00-31 day of the month.
    • _NOTETIME - The current time. Fields from the note time are inserted with these symbols:
      • _NOTEHOUR for the 00-23 hour, _NOTEMIN for a 00-59 minute, or _NOTESEC for a 00-59 second.
  • Message Information:
    • _MSGDATE - The message date. Fields from the message date are inserted with these other symbols:
      • _MSGYEAR for a 4 digit year, _MSGMONTH for a 01-12 month, or _MSGDAY for a 00-31 day of the month.
    • _MSGTIME - The message time. Fields from the message time are inserted with these symbols:
      • _MSGHOUR for the 00-23 hour, _MSGMIN for a 00-59 minute, or _MSGSEC for a 00-59 second.
    • _MSGSUBJECT - The message subject.
    • _MSGRECIPENTS - List of all message recipients (in the email "to" field).
      • Similarly, _MSGCC will list the addresses from the "cc" field and _MSGBCC will list the addresses from "bcc"
    • _MSGAUTHOR - The message author.
    • _MSGATTACHMENTLIST - A list of the message attachments saved to Trilium Notes. If no message attachments were saved, returns the string "none."
    • _MSGIDURI - A URI that can be clicked to open the message.
      • For example, combining the text in the field 'Message Link Text' _MSGURI will create a link in your note that when clicked will open the email in your client.
    • _MSGCONTENT - The actual text content of the message.

For example, if you use the filename template of 'Email (_MSGDATE) : _MSGSUBJECT', your clipped notes will have titles of the form 'Email (02⧸30⧸2023) ꞉ Single WOmbats in your area whant to Chat!' (assuming, of course, that single wombats in your area reached out to you to chat on February 30th, 2023).

Be sure to include the leading underscore ("_") and all capital letters ("_MSGAUTHOR") when using any of the above placeholders in your template.

Maximum Clipped Email Note Size

To conserve space in your vault or to resolve certain technical problems, you may want to limit the size of the emails clipped to Trilium Notes. If you set a limit below, Trilium Clipper will crop an email to the size you choose. To activate this feature, enter the maximum email size. A nonnumeric value (such as the text "disabled") disables this feature.
